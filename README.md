## Business Case

The working group's draft business case documentation is available in this repository. Once the documentation is finalized, it will be formally published on the [IRI DFA Library of Standards](https://www.irionline.org/member-programs/operations-technology/digital-first-library-standards/).

Today, non-financial transaction requests are highly inconsistent across the carriers and transaction types. These capabilities represent high-volume operational processes that remain largely manual and fragmented across the industry today.

## Key Outcomes:

- Improves Operational Efficiency: Standardized digital workflows help automate high-volume non-financial servicing transactions that remain largely manual and fragmented today.

- Reduces Processing Risk: Common business requirements and standardized API specifications reduce operational friction and risk associated with inconsistent servicing processes.

- Improved Financial Professional and Customer Experiences: More efficient digital processing of owner, party, demographic, and representative changes creates a more consistent servicing experience.

- Enables Industry Interoperability: Common standards provide a consistent framework for carriers, distributors, technology providers, and service platforms to process and exchange non-financial transaction information.

- Accelerates Digital Modernization: Standardized REST/JSON APIs support the industry's transition from legacy SOAP/XML messaging and manual processes to modern, API-driven workflows.

- Drives Consistent Industry Adoption: Agreed-upon standards and implementable API specifications support scalable adoption of non-financial transaction capabilities across the industry.

## User Stories, personna - supporting documents for the business case
- Use Case 1: Establish a consistent, interoperable framework that enables carriers, distributors, technology providers, and service platforms to automate these servicing events while reducing operational friction.
